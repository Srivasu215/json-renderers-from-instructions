Word 3

The Verb "FORM": Shaping the Spec

What does it mean to "form"? It means taking unstructured, amorphous data and giving it shape, hierarchy, and visual structure according to the recipe.

1

Skeleton Initialization

The engine clones a clean base specification (base.json) from the definition catalog. At this stage, the table is empty—it contains container tags with empty child arrays.

2

Registry Assembly

The runtime creates the central state registry containing raw data, columns, options, and the target base specification: 

const registry = {
  data: { columns, data },
  base,
  ...options
};
3

Instruction Execution (The Shaping Pass)

json-renderers-run-instructions executes the single and double instructions. It iterates over columns and data, resolves path pointers, and populates the tree with headers, rows, and cells.

4

Feature Option Hydration

Any enabled options (e.g. serial numbers, search input, actions) run through the options transformer, modifying the formed specification to inject serial number headers and cells.

The Secret: Zero DOM in the Forming Pass

Notice that throughout steps 1 to 4, not a single browser DOM node is created. There is no document, no window, and no layout calculation.

The output is a pure Virtual JSON DOM specification tree: an exact, predictable representation of the UI ready for stamping.
