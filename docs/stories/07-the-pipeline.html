The Ecosystem

The Complete Pipeline

No single library should try to do everything. Discover how the KeshavSoft ecosystem organizes data, recipes, computation, and rendering into clean, isolated layers.

1. spec-repo The Catalog: stores base templates and instruction JSON files
2. json-renderers-run-instructions The Engine: interprets 1D single & 2D double instructions
3. json-renderers-build-table-options The Transformer: injects options (serials, search, actions)
4. json-renderers-from-instructions The Orchestrator: coordinates validation, build, and mount passes
5. @keshavsoft/json-to-dom The Craftsman: stamps the spec into live browser DOM elements

Single Responsibility in Practice

Each layer operates with zero unnecessary dependencies:

  • spec-repo knows nothing about JavaScript—it is pure JSON definitions.
  • json-renderers-run-instructions knows nothing about the browser DOM—it is pure functional data transformation.
  • @keshavsoft/json-to-dom knows nothing about tables or data schemas—it simply creates DOM nodes from any valid JSON spec tree.
