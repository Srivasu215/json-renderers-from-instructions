The Monaco Studio: Live Instruction Design

Because instructions are pure JSON data, you don't need a compiler to alter UI layouts. You can edit them live in your browser and see the results form in real time.

Launch the In-Browser Monaco Workbench

Edit definitions, columns, and instructions interactively inside Monaco Editor.

Open Monaco Studio ↗

What You Can Do in the Studio

  • Edit Columns Live: Modify labels, field bindings, or add custom classes directly in columns.json.
  • Tweak 1D Instructions: Alter how headers are generated in columnSpec.json.
  • Tweak 2D Instructions: Customize cell formatting and row attributes in rowSpec.json.
  • Instant Visual Feedback: Watch the table re-form immediately with zero browser refresh or bundling step.
